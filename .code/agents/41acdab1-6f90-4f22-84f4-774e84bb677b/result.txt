- Cookies/HTTPS
  - `Cookie.SameSite = Lax`, `Cookie.SecurePolicy = Always`, `Cookie.HttpOnly = Always`.
  - `UseHttpsRedirection`; `UseHsts` in Production.
  - Forward headers config when behind reverse proxy.

- Rate Limiting/Brute Force
  - .NET 8 `AddRateLimiter` on login/Ajax; small burst then steady limit.

- Authorization
  - `[Authorize(Roles="Admin")]` for admin-only.
  - Documents controller: explicit ownership/admin checks.
  - AccessDenied path wired and styled.

- File Upload Safety

  - Validate extension and content-type; compute SHA256; store outside web root.
  - Optional AV hook (ClamAV) or quarantine flow; at minimum a denylist for executables.
